BIRTHDAY SURPRISE WEBSITE
=========================

Files:
- index.html      Page 1: The Beginning
- story.html      Page 2: Our Little Story
- reasons.html    Page 3: Why You're Special
- memories.html   Page 4: Moments I Remember
- letter.html     Page 5: A Letter From Me
- surprise.html   Page 6: The Final Surprise
- style.css       Shared responsive styling and photo gallery styles
- script.js       Shared interactions and animations
- images/         The three actual memory photos used by memories.html

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with the Live Server extension.
4. Click through the pages using the navigation buttons.

PHOTO MEMORIES
The Memories page already contains all three supplied photos as static files:
- images/memory-01.png — the WhatsApp message
- images/memory-02.jpg — the 2005 / 2026 photograph
- images/memory-03.jpg — the ring and red charm on the keyboard

Keep the images folder beside the HTML files when running or deploying the site.
The photos are bundled with the website; they do not depend on Chrome storage,
IndexedDB, or selecting files after the page opens.

DEPLOYMENT
Upload the complete extracted project folder, including images/, to your hosting
provider (for example, Vercel or Netlify). Do not upload only the HTML files.

Google Fonts requires an internet connection. The site still works without it,
using fallback fonts. Review the wording in the story, reasons, and letter pages
before sharing if you want to personalize those messages further.
